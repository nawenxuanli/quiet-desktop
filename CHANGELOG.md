# Changelog

## 1.6.0 — 2026-10-29

- Add a native Windows x64 edition with app shortcuts, notes, photo cropping, and System/Light/Dark appearance.
- Add a Windows build workflow, native smoke checks, portable ZIP, and identity-validated Microsoft Store packaging.
- Add a public privacy policy. macOS version 1.5.0 remains available.

## 1.5.0 — 2026-10-27

- Add System, Light, and Dark appearance selection.
- System follows macOS appearance changes automatically; the selection saves locally.

## 1.4.0 — 2026-10-27

- Add the Quiet Desktop app icon and source build script.
- Package the clock, app search, editable favorites, local notes, and folder shortcuts.
- Include photo selection with rounded edge-to-edge display and crop controls.
- Add setup instructions, privacy details, and known limitations.
